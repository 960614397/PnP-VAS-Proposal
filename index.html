New value inside PnP Mobile, for every Smart Shopper.

Pick n Pay already runs PnP Mobile and Smart Shopper — a live network and a 16-million-member loyalty base. This proposal doesn't ask Pick n Pay to build anything new. The Opportunity

PnP Mobile and Smart Shopper already do the hard part — attach, don't rebuild.

Every day, PnP Mobile subscribers top up airtime and data, and Smart Shopper members earn points on groceries. Today none of that spend is protected against fraud, identity theft or data loss while travelling, and there's no prepaid AI option at all. Four new VAS close those gaps, on infrastructure that already exists.

01

Existing base, new revenue

No new subscribers to acquire — every current PnP Mobile SIM is a live attach opportunity.

02

One loyalty number, four products

Smart Shopper already identifies the customer — Bitdefender, eInsurer and Travel eSIM ride on the same number; My Instant AI sells as a standalone voucher through the same app and till.

03

No network to build

These are app-level, billing-level and voucher-level attachments, not infrastructure — live in weeks via API integration.

Why this is low-risk

Bitdefender and eInsurer already run inside comparable connectivity brands' plans at scale, with proven attach-rate ranges and pricing. This is not an experimental product — it's a proven attach model, applied to a base Pick n Pay already owns.

How the pricing works

Tokens are the unit of use. A question and its answer spend a few hundred tokens, so a R20 card carries a shopper for weeks of light use. The bigger the card, the more tokens per rand, which gives the shopper a reason to trade up and Pick n Pay a reason to stock all three.
